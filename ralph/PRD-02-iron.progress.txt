T1: the wire protocols in two languages. packages/protocol (tag internal, tsdown to dist/index.mjs only so plain-Node scripts can import the Zod): the server link at /link — up: hello (server token, plugin/SDK/CSS/MatchZy/Metamod versions, capabilities, installed plugin folders, hostname, map, state, matchId?, lastSeq), heartbeat, state (booting|idle|assigned|live|ending|draining), events (batch ≤200 of {seq, event} with a per-server link seq distinct from the vocabulary's per-match hint), command_result (applied|rejected + the Match API error code), backup ({mapNumber, roundNumber, filename, content ≤256 KiB}), console (uptime-stamped tail ≤500, on demand), player_command_result (closed refusal set: cooldown, no_charges, unknown_command, invalid_args, not_in_match, not_alive, refused); down: welcome (provider + serverId = the event source, heartbeatIntervalMs, ackedSeq), assign (matchId, game, the manifest resolved minus maps/widget, plugins, cfg, cvars merged flat, matchzyConfig? opaque for T9, maps, rules?, teams with profiles+loadouts, warmupLines, branding, demoUploadUrl?, restore?), command (a Match API MatchCommand verbatim minus sim.*, plus the link-only console), player_command, profile, release, drain, ack (accepted|duplicate|ephemeral|rejected — the platform's ingestion vocabulary plus rejected so a malformed event is never retried). The node link at /node — up: hello (enrolment|node token, version, region, lan, labels, capacity {maxInstances, warm}, sha256 image digest, instances snapshot), heartbeat, instances; down: welcome (nodeToken once, after an enrolment hello), start (instance spec: id, purpose warm|match, image, serverId, serverToken, ports, env, matchId?), stop, drain, undrain; nothing acked, instances is a snapshot. Constants (PROTOCOL_VERSION 1, paths, HEARTBEAT 10 s, HELLO_TIMEOUT 10 s, batch/backup/console limits, LINK_CLOSE_CODES 4001–4012) ride into the JSON Schema as x-constants and into C# as ProtocolConstants. Codegen decision: NJsonSchema 11.6 and quicktype-core 26 were both run on the real GameserverEvent schema — NJsonSchema keeps only the first oneOf branch (even with a discriminator hint), quicktype merges all 22 into one class of optionals with invented names, and neither distinguishes an absent optional from an explicit null — so neither could round-trip the goldens byte for byte; scripts/protocol-codegen.mjs is our own ~400-line generator over the exported JSON Schema (records in schema order with JsonPropertyOrder, required/init, optional → WhenWritingNull, nullable → T?, optional+nullable refused, defaults as initializers, consts get-only, enums with JsonStringEnumMemberName, an abstract record + dispatching converter per union registered on ProtocolJson.Options, doubles written like JavaScript so 0.000001 stays 0.000001); `pnpm lint` runs it with --check, `pnpm build` writes it. JSON Schema export is z.toJSONSchema over a registry in output mode (defaults filled = the bytes the producing side writes), names decided once in src/schema.ts; only the server link has a C# side (the node agent is TS).
